# 전생 마스코트 — 외국 시대 20종

기존 서비스 무지개 젤리 마스코트를 사용한 중세~르네상스 유럽풍 직업 이미지입니다. 20종 모두 입 없이 눈과 소품으로 표현했습니다.

- png/: 투명 생성 원본 20종
- webp/: 앱용 512×512 투명 WebP 20종
- preview.jpg: 원래 목록 순서의 4열×5행 전체 미리보기
- preview-dark.jpg: 어두운 배경 미리보기
- manifest.json: 생성 도구, 프롬프트 및 원본 경로
- validation.json: 파일 수, 투명도 및 WebP 알파 보존 검사

Built-in image_gen 사용. 한국 버전은 별도 폴더에 유지하며, 서당 훈장의 입 제거도 유지됩니다. 앱 화면 연결은 하지 않았습니다.
