# 전생 직업 마스코트 20종

기존 서비스 마스코트와 MBTI intj/enfp 이미지를 참조해 built-in image_gen으로 생성했습니다. 한국 시대 직업 표현 기준입니다.

- png/: 투명 배경 생성 원본 20종
- webp/: 앱용 512×512 투명 WebP 20종
- preview.jpg: 요청 순서로 배치한 4열×5행 전체 미리보기
- manifest.json: 직업명, 전체 생성 프롬프트, 참조 경로
- validation.json: 이미지 크기, 알파 채널, WebP 용량 검사

이미지 제작 결과물이며 화면 연결은 하지 않았습니다.
