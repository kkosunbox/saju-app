# 운Pick 브랜드 가이드

> **오늘의 운, 하나만 Pick!**

## 이름
- **운Pick** (읽기: 운픽, 영문 도메인 표기: woonpick). 오늘의 운을 하나 뽑는다는 뜻이에요.
- 매일 열어 하나를 뽑고, 친구에게 "오늘 내 운픽 뭐 나왔어?" 하고 나누는 습관을 이름에 담았어요.
- 표기: 로고·화면은 `운Pick`, 문장 속에서는 `운픽`도 써요. 슬로건 `오늘의 운, 하나만 Pick!`
- 스토어 이름: `운Pick - 오늘의 운, 하나만 Pick`

## 핵심 카피 (`src/content/copy.ts`)
| 카피 | 쓰는 곳 |
|---|---|
| 오늘의 운, 하나만 Pick! | 슬로건 · 스플래시 · 스토어 이름 |
| 오늘, 어떤 운을 PICK하시겠어요? | 로그인 · 온보딩 첫 장 · 아침 알림 |
| 사주부터 MBTI까지, 오늘의 나를 PICK하다. | 로그인 · 온보딩 · 스토어 부제 |
| 네 가지 관점으로 고른, 오늘 나에게 맞는 운 | 운세 탭 |
| 궁금한 운만 골라서 PICK | 콘텐츠 탭 |
| 친구의 운도 PICK해 볼까요? | 무료 콘텐츠 · 공유 블록 |
| 더 깊이 알고 싶은 운, 하나 더 PICK | 유료 추천 |
| 내일도 하나 PICK하러 와요 | 홈 맨 아래 |

'PICK'은 고르는 동작을 강조할 때 대문자로, 브랜드명은 `운Pick`으로 써요. 카피에도 이모지는 쓰지 않아요.

## 로고 — 직접 그린 레터링 + 부적 (`docs/wordmark.png`)
| 요소 | 설명 |
|---|---|
| 워드마크 **운Pick** | 글꼴이 아니라 직접 그린 단선 레터링. 획 두께 11 · 둥근 끝 · '운'과 'Pick'의 높이·두께를 하나로 맞춤 |
| 시그니처 **부적** | '운'의 ㅜ 기둥 자리에 **붉은 매듭 끈**으로 매달린 노란 부적(-7°) — 위아래 붉은 두 줄 · 붉은 도장 · 웃는 눈(∩∩)과 입 · 볼 · 접힌 그림자 |
| 앱 아이콘 | 워드마크의 '운'+부적을 한지색 바탕 위에 (`assets/icon.png`) |
| 사용 규칙 | 한 화면에 로고는 하나만. 첫 화면·헤더·공유 카드는 워드마크, 앱 아이콘·로딩·작은 자리는 '운' 마크 |
| 코드 | `src/components/BrandMark.tsx` — `BrandMark`(워드마크) · `LogoMark`('운'). `npm run icons`가 같은 패스로 아이콘을 만들어요 |

- 부적 색: 종이 `#EFCB63`, 볼 `#E07C6A`(50%), 끈·도장·두 줄은 낙관 주홍. 표정이나 도장만 바꿔 변형할 수 있어요.
- 회전·변형 속성 없이 좌표로만 그려 앱·웹·공유 이미지에서 같은 모양이에요.
- 쓰지 않는 것: 초승달·별·반짝이(✦)·보라 그라데이션·네온.

## 서체
- **제목 · 본문 · UI: Pretendard** — 로고의 둥근 단선 레터링과 어울리는 현대 고딕. 굵기 400(본문) · 500(작은 글) · 600(강조) · 700(제목)
- **강조: Noto Serif KR** — 큰 숫자(점수) · 한자 낙관 · 책력 카드 제목 · 인용 풀이. 한자까지 같은 서체라 화면마다 한자 모양이 달라지지 않아요
- 코드: `src/theme/typography.ts` — `fonts.display`(제목) · `fonts.serif`(강조) · `sansW(굵기)`(본문). 네이티브는 굵기별 파일(`assets/fonts`, Noto는 `@expo-google-fonts/noto-serif-kr`)
- 라이선스: 둘 다 SIL Open Font License (`assets/fonts/LICENSE-*.txt`)
- 한자는 표식으로만 써요(緣 연애, 財 재물, 業 직장, 人 관계, 封 잠금).

## 말투 (AI 같지 않게)
- 친구에게 말하듯 짧게. 공유 문구는 반말: "나 전생에 '발해의 서당 훈장'이었대. 너는?"
- **이모지를 쓰지 않아요.** "AI가 분석한", "엔진" 같은 말도 화면에 쓰지 않아요.
- 단정하지 않아요. "~하기 좋은 흐름이에요". 중요한 결정은 전문가 상담을 권해요.
- 숫자로 말해요: 점수, 달, 요일, 날짜.

## 화면 모드
- 마이 > 화면 모드에서 시스템 · 라이트 · 다크를 골라요. 모든 화면이 두 팔레트를 함께 지원해요(공유 카드는 항상 한지).

## 화면 디자인 원칙 — 책력 한 장
- 밋밋한 박스·가운데 정렬 대신 **책력 지면**처럼: 이중 테두리 · 모서리 꺾쇠 · 한자 제호(四柱·七曜·性向·血型 등) · 왼쪽 정렬 명조 · 비스듬한 낙관 · 옅은 워터마크.
- 정보는 글 나열보다 **도해**로: 사주 원국표·오행 막대, 일곱 요일 띠, MBTI 4축, 혈액형 표.
- 목록은 **장부형**(一·二·三 번호 + 점선 구분), 풀이는 **인용형**(왼쪽 색 띠 + 명조).
- 섹션 제목은 제목 옆으로 가는 선, "01 · 제목"은 번호를 낙관색으로.
- 부품: `src/components/Almanac.tsx`(AlmanacHero · Figure · Ledger · Quote), `SectionHeader`(HeadTitle), 유료 Hero·홈 오늘의 카드의 책력 테두리.

## 공유 카드

- 개인정보(생년월일, 고민 원문)는 넣지 않아요.
