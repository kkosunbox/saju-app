# 운Pick 브랜드 가이드

> **오늘의 운, 하나만 Pick!**

## 이름
- **운Pick** (읽기: 운픽, 영문 도메인 표기: woonpick). 오늘의 운을 하나 뽑는다는 뜻이에요.
- 매일 열어 하나를 뽑고, 친구에게 "오늘 내 운픽 뭐 나왔어?" 하고 나누는 습관을 이름에 담았어요.
- 표기: 로고·화면은 `운Pick`, 문장 속에서는 `운픽`도 써요. 슬로건 `오늘의 운, 하나만 Pick!`
- 스토어 이름: `운Pick - 오늘의 운, 하나만 Pick`

## 핵심 카피 (`src/content/copy.ts`)
| 카피 | 쓰는 곳 |
|---|---|
| 오늘의 운, 하나만 Pick! | 슬로건 · 스플래시 · 스토어 이름 |
| 오늘, 어떤 운을 PICK하시겠어요? | 로그인 · 온보딩 첫 장 · 아침 알림 |
| 사주부터 MBTI까지, 오늘의 나를 PICK하다. | 로그인 · 온보딩 · 스토어 부제 |
| 네 가지 관점으로 고른, 오늘 나에게 맞는 운 | 운세 탭 |
| 궁금한 운만 골라서 PICK | 콘텐츠 탭 |
| 친구의 운도 PICK해 볼까요? | 무료 콘텐츠 · 공유 블록 |
| 더 깊이 알고 싶은 운, 하나 더 PICK | 유료 추천 |
| 내일도 하나 PICK하러 와요 | 홈 맨 아래 |

'PICK'은 고르는 동작을 강조할 때 대문자로, 브랜드명은 `운Pick`으로 써요. 카피에도 이모지는 쓰지 않아요.

## 로고 — 마스코트 + '운픽' 레터링 (Figma '사주앱' 파일)
| 요소 | 설명 |
|---|---|
| 마스코트 | 무지개빛 젤리 캐릭터(동그란 두 눈). 홈 말풍선 아래 · 상담가 얼굴 · 빈 자리 장식 · 관점별 포즈(사주 부적 · 점성술 행성 · MBTI 헤드폰 · 혈액형 하트) |
| 워드마크 **운픽** | 마스코트 얼굴 + '운픽' 레터링. 하늘색·어두운 바탕엔 흰 글자, 밝은 바탕엔 먹색 글자 |
| 앱 아이콘 | 하늘색 그라디언트 위 마스코트 (`assets/icon.png`, 안드로이드 배경 `#7FD0FF`) |
| 코드 | `src/components/Mascot.tsx` — `Mascot`(그림 · 포즈) · `Logo`(워드마크). `BrandMark`·`LogoMark`는 이 둘을 감싼 예전 이름 |

- 그림 원본은 Figma에서 받아 화면 크기의 2~3배로 줄여 `assets/images`에 둬요. 사주 캐릭터 그림은 아직 호랑이 하나뿐이에요.

## 서체
- **모두 Pretendard.** 굵기 400(본문) · 500(작은 글) · 600(제목) · 700~800(강조 · 큰 숫자). 자간은 -0.04em 정도로 좁게.
- 코드: `src/theme/typography.ts` — `txt`(크기 단계) · `sansW(굵기)`. `fonts.serif`는 예전 명조 자리를 표시하는 이름으로 남아 있고 지금은 Pretendard Bold예요.
- 한자는 표식으로만 써요(사주 원국 · 부적 · 일주 등 내용 자체가 한자인 곳).

## 말투 (AI 같지 않게)
- 친구에게 말하듯 짧게. 공유 문구는 반말: "나 전생에 '발해의 서당 훈장'이었대. 너는?"
- **이모지를 쓰지 않아요.** "AI가 분석한", "엔진" 같은 말도 화면에 쓰지 않아요.
- 단정하지 않아요. "~하기 좋은 흐름이에요". 중요한 결정은 전문가 상담을 권해요.
- 숫자로 말해요: 점수, 달, 요일, 날짜.

## 포인트
- 포인트 단위는 **알**이에요(1,000원 = 100알). 동전 그림 안의 글자는 P 그대로 둬요.

## 화면 모드
- 마이 > 화면 모드에서 시스템 · 라이트 · 다크를 골라요. 디자인은 라이트 기준이고 다크는 같은 구조를 어두운 팔레트로 보여 줘요(공유 카드 · 부적 카드는 항상 밝게).

## 화면 디자인 원칙 — 깔끔한 카드 + 마스코트
- 흰 바탕에 연회색 카드(반경 12), 선과 그림자는 거의 쓰지 않아요. 떠 있는 것(말풍선 · 하단 탭바)만 옅은 그림자.
- 섹션 제목은 "제목 | 설명" 한 줄, 오른쪽 끝에 › 버튼.
- 유료 콘텐츠 안내는 어두운 남색 카드(제목은 연한 노랑·연두, 오른쪽 아래 마스코트 실루엣, 아래 알약 버튼).
- 강조 상자(입력창 · 공유 블록 · 잠금 안내 · 인생 패키지)는 하늘색 그라디언트 테두리.
- 부품: `PromoCard` · `GradientBorder` · `CategoryRow` · `CategoryIcon` · `AnalysisTile` · `HeaderPoints` · `Almanac`(상세 화면 첫 카드).

## 공유 카드
- 9:16(1080×1920) 밝은 단일 테마. 하늘색 그라디언트 위 로고 · 흰 말풍선 결과 · 마스코트 · 회색 숫자 칸 · 잠긴 이야기 · 질문형 마무리.
- 문구 속 브랜드는 `운Pick`으로 써도 돼요(로고는 운픽).
- 개인정보(생년월일, 고민 원문)는 넣지 않아요.
