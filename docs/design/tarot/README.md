# 운Pick 메이저 아르카나 이미지 덱

메이저 22장(00–21)과 뒷면(back)을 각각 별도의 이미지로 생성했다. 내장 `image_gen.imagegen` 도구를 사용했으며 CLI/API 대체 경로는 사용하지 않았다.

## 방향과 참고

라이더–웨이트–스미스의 인물 배치와 주요 상징을 참고한 새로운 회화 해석이다. 인디고·청록·금색·버밀리언, 수채·과슈 질감, 아이보리 여백과 금색 테두리를 한 덱 전체에 맞췄다. `17 / The Star`를 화풍 기준으로 삼고 나머지 카드를 개별 생성했다. 번호와 이름은 앱이 별도로 표시하므로 그림 안에는 넣지 않았다.

- 실제 덱 이미지 참고: https://commons.wikimedia.org/wiki/File:Rider-Waite_Major_Arcana_full.png
- 원본 이미지 참고 파일: reference-major-arcana.png
- 상징 설명 참고: https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot/Part_2
- 전체 프롬프트와 생성 파일 매핑: generation-prompts.json

## 파일

- 고해상도 원본 23장: ../../../assets/tarot/source/ (1024×1536 PNG)
- 앱 표시용 23장: ../../../assets/tarot/ (768×1152 WebP)
- 전체 덱 미리보기: deck-preview.jpg

화면은 `TarotCard.tsx`의 고정 require 목록을 통해 이미지 파일을 묶는다. 홈의 카드 뒷면과 상세·테마·공유 화면 모두 같은 덱을 사용한다. 그림 위에 별도 젤리 마스코트를 덧붙이지 않는다. 20px 관점 아이콘은 기존 벡터 아이콘을 유지한다.

원본의 인물·배경과 주요 상징을 시각적으로 점검했다. 바보 카드의 팔 표현은 생성 도구로 두 차례 수정했으며, 수정 프롬프트도 매핑 파일에 기록했다.

## 검증

23개 PNG 원본이 서로 다른 이미지인지, 모두 1024×1536인지 확인했다. 앱용 WebP는 전부 768×1152이며 총 약 9.4MB다. 원본 PNG는 화면에서 가져오지 않고 WebP만 묶는다.

앱 타입 검사 통과, lint 오류 0(프로젝트 경고 129), 웹 빌드와 iOS·Android·웹 export를 확인했다. 로컬 테스트 API 응답으로 모바일 상세·공유·다크 모드의 실제 이미지 로드를 확인했고 브라우저 실행 오류는 없었다. 이 이미지 변경은 아직 커밋·배포하지 않았다.
