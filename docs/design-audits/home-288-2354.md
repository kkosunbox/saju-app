## 유지한 동작과 비교상 차이

- 운세·점수·키워드·사주 캐릭터·분석 결과는 실제 사용자 데이터이다. 예시 문장을 강제로 넣거나 카드 높이를 고정하지 않는다. 따라서 본문 줄 수와 하위 섹션의 절대 y좌표는 Figma 예시와 달라질 수 있다.
- 긴 행운 컬러명·시간은 잘리지 않게 줄바꿈한다. 한 줄인 Figma 예시와 달리 두 줄이면 흰 칸의 높이가 늘어난다.
- 일부 자동 텍스트 폭은 Figma의 경계값과 브라우저의 소수점 계산에 차이가 남는다. 글자 크기·굵기·자간·대응 행간은 위 표대로 확인했다. 배지·타일·라벨 그룹·탭 등 고정 슬롯은 원본 크기에 맞췄다. 행동 탭의 균등 분할 폭은 157.5px이다(Figma 예시 158/157px).
- 홈 루트에는 기존대로 뒤로가기를 추가하지 않았다. 따라서 Figma의 뒤로가기(x=24)와 그 옆 로고(x=55) 배치 대신 로고를 x=24에 둔다. 로고 자체 크기·세로 위치는 맞췄다.
- Figma의 `연예` 오자는 기존의 올바른 이름 `연애`로 유지한다.
- 배우자 배너의 `100P · 상담 시작하기`는 해당 기능과 다른 디자인 문구이므로 실제 가격·리포트 열기 동작을 유지한다. 포인트 단위도 앱의 알 아이콘을 유지한다.
- 체크 상태·진행 개수·미공개 표시·추가 무료 카드·추가 콘텐츠 링크·사업자 푸터·개발 도구를 유지한다.
- 뽑기 전 링과 상하 여백은 이후 사용자 요청으로 다듬은 상태를 유지한다. 공개 후 키워드 y=315px(디자인 y=359−상태바44)을 다시 확인했다.
