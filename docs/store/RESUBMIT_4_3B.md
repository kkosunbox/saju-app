# 4.3(b) 재심사 제출 가이드

> 2026-11-19 · 거절 사유: Guideline 4.3(b) Design – Spam (운세 카테고리 포화)
> 이 문서는 **실제로 바뀐 앱 기준**으로 정리했어요. 개편 계획은 `REPOSITION_CONSULT.md`에 있고, 그중 일부(첫 사용 동의 모달, 하단 상담전화 안내, 1년 자동 삭제)는 개편 중에 바뀌었으니 **이 문서를 기준으로** 써요.

---

## 1. 한 줄 포지셔닝

> **"오늘의 운세 앱"이 아니라, 사주와 MBTI로 나를 먼저 이해한 AI와 내 고민을 대화로 푸는 앱.**

심사관이 보는 순서는 **아이콘·이름 → 스크린샷 1~2장 → 앱 첫 화면 → 해결 센터 답장**이에요. 네 군데 모두에서 "채팅 앱"으로 읽혀야 해요.
4.3(b)는 "다른 운세 앱과 무엇이 다른가"를 묻는 거라서, **기능 나열보다 차이점 3~4개**를 반복해서 보여 주는 게 핵심이에요.

---

## 2. 무엇이 달라졌나 (어필 포인트)

심사에서 내세울 차이점이에요. 앱에 실제로 있는 것만 적었어요.

| # | 차이점 | 앱에서 보이는 곳 |
|---|---|---|
| 1 | **첫 화면이 대화창** — 앱을 열면 운알톡(입력창 + 최근 대화)이 바로 나와요. 운세 목록·타로 탭이 없어요 | 하단 탭 `운알톡 · 대화 기록 · 리포트 · 마이`, 운알톡이 첫 탭 |
| 2 | **내 말로 쓴 고민에 맞춘 답 + 이어 묻기** — 정해진 운세 문구가 아니라, 사용자가 쓴 고민과 그 사람의 사주·MBTI를 함께 보고 답해요. 답을 받은 뒤 24시간 동안 10번 더 물어볼 수 있어요 | 상담 대화 화면 |
| 3 | **대화가 리포트로 이어지는 흐름** — 답변 끝에 고민 주제에 맞는 심층 리포트 하나를 추천해요 (예: 육아 고민 → 우리 아이 사주) | 상담 답변 아래 추천 카드 |
| 4 | **대화 기록** — 고민과 답이 한 달씩 쌓이고, 사이드 메뉴(☰)에서 지난 대화를 바로 열어요. ChatGPT식 대화 앱 구조 | 대화 기록 탭, ☰ 메뉴 |
| 5 | **오늘의 운세도 대화 안에서** — 따로 뽑는 운세 화면 없이, "오늘 운세 어때?"라고 물으면 운알이가 대화로 답해요 | 운알톡 홈의 오늘의 운세 카드 → 대화 화면 |
| 6 | **차별화 리포트** — 우리 아이 사주(아이 기질·재능·공부 방식 + 보호자 1~2명과의 관계), 미래 배우자(사주로 그린 얼굴), 링크로 상대와 함께 보는 궁합 | 리포트 탭 |
| 7 | **안전 장치** — 위기 신호가 보이는 고민에는 리포트를 권하지 않고 상담전화 카드(109 · 1577-0199 · 1388)를 답 위에 띄워요 | 상담 답변 |

### 내세우지 말 것 (사실과 다르거나 역효과)

- "1년 뒤 자동 삭제" — **정책을 없앴어요.** 지금은 "언제든 직접 지울 수 있고 탈퇴 시 삭제"
- "처음 사용할 때 AI 전송 동의를 받는다" — 별도 모달은 없앴어요. 지금은 **첫 프로필 저장 전 약관·개인정보 동의**(OpenAI 국외 이전 고지 포함)
- "앱이 전문 상담을 대신하지 않는다고 화면에 안내한다" — 상시 안내 문구는 뺐어요. 위기 신호일 때만 상담전화 카드가 떠요
- 운세 점수, 타로, 띠운세, 전생 같은 단어를 이름·부제·스크린샷 1~2장에 넣는 것

### 설명

```
말 못 할 고민, 누구에게 털어놓으세요?

운Pick의 운알톡은 사주와 MBTI로 나를 먼저 이해한 뒤
내가 쓴 고민에 맞춰 대화로 답해 주는 AI 고민상담이에요.
정해진 운세 문구가 아니라, 지금 내 상황에 대한 이야기를 나눠요.

■ 나를 아는 AI, 운알이와 대화
· 연애 · 인간관계 · 일과 진로 · 육아 · 돈, 어떤 고민이든
· 내 타고난 성향(사주 · MBTI)을 바탕으로 한 맞춤 답변
· 답을 받은 뒤에도 이어서 더 물어볼 수 있어요
· 대화는 나만 볼 수 있고, 언제든 직접 지울 수 있어요

■ 대화가 쌓이는 기록
· 지난 고민과 답을 한곳에서 다시 보기
· 메뉴에서 지난 대화를 바로 이어 가기

■ 더 깊이 알고 싶을 때, 리포트
· 우리 아이 사주 – 아이의 기질, 재능, 공부 방식, 보호자와의 관계
· 미래 배우자 리포트 – 사주로 그린 배우자의 모습과 만나는 때
· 궁합 – 링크 하나로 상대와 함께
· 상세 사주 해석 · 평생운 · 신년 흐름
대화 중 필요한 리포트를 운알이가 먼저 추천해 줘요.

■ 매일 가볍게
· "오늘 운세 어때?" 한마디면 운알이가 오늘 하루를 정리해 줘요

■ 이런 분께
· 주변에 말하기 어려운 고민이 있는 분
· 내가 왜 이런 선택을 반복하는지 알고 싶은 분
· 아이를 더 잘 이해하고 싶은 보호자

운알톡은 전문 심리상담이나 의료·법률·금전 상담을 대신하지 않아요.
힘든 순간에는 자살예방 상담전화 109, 정신건강 위기상담 1577-0199로 연락해 주세요.
고민 글은 답변 작성을 위해 OpenAI(미국)로 전송돼요.
```

## 4. 스크린샷 (6장)

순서가 곧 첫인상이에요. **1~2장만 보고도 채팅 앱**으로 보여야 해요.

| # | 화면 | 상단 문구 |
|---|---|---|
| 1 | 운알톡 상담 대화 (고민 → 맞춤 답변) | 말 못 할 고민, 운알이에게 |
| 2 | 이어 묻기 (후속 질문과 답) | 궁금한 건 이어서 더 물어봐요 |
| 3 | 운알톡 홈 (입력창 · 최근 대화) | 나를 아는 AI와 나누는 고민 대화 |
| 4 | 답변 아래 리포트 추천 → 우리 아이 사주 | 필요한 리포트는 운알이가 먼저 |
| 5 | ☰ 메뉴 또는 대화 기록 탭 | 고민과 답이 차곡차곡 쌓여요 |
| 6 | 오늘의 운세 대화 | 오늘 하루도 운알이에게 물어봐요 |

- 1장은 **대화 화면**으로 시작하는 걸 추천해요. 홈보다 "채팅 앱"이라는 게 한눈에 보여요.
- 점수가 크게 보이는 오늘의 운세는 마지막 6장에만, 그것도 대화 모양이 보이게 찍어요.
- 타로 카드, 부적, 전생, 띠운세 화면은 넣지 않아요.
- 심사 계정의 실제 대화로 찍어요. 고민 글은 연애 · 육아 · 직장처럼 주제가 다양하게.

## 6. 해결 센터 답장 (영문)

```
Hello App Review Team,

Thank you for your feedback regarding Guideline 4.3(b).

We understand that fortune-telling apps are a saturated category. We have rebuilt the app so
that its core experience is a personal AI conversation, not daily fortunes.

1. A conversation app first
   The app now opens directly to "Unaltalk", a chat where users describe a personal concern
   in their own words. Past conversations are kept in a chat history (side menu and a
   dedicated tab), like a messaging app. There is no fortune list or tarot tab anymore,
   and even the daily fortune is now an answer inside the conversation.

2. Replies written for one person and one concern
   Each reply is grounded in the specific concern the user wrote and in their own profile
   (Korean Saju birth chart and MBTI). Users can ask follow-up questions on the same
   conversation, so the experience is a dialogue rather than a generic reading.

   When relevant, the conversation recommends one in-depth report. For example, a parent
```

- [ ] 데모 영상(1분 안팎): 홈 → 고민 입력 → 답변 → 이어 묻기 → 리포트 추천 → ☰ 메뉴
